# 리뷰어 aQS2 대응 전략

점수 2, 확신 3. Soundness 3, Clarity 3, Contribution 2.

## 리뷰 요지

- **강점으로 인정한 것**: 방법이 명확하고 모듈식이며 여러 PINN 구조와 호환됨(S1), 실제 유동 측정 평가(S2).
- **W1**: 잔차 밀도만으로는 측정 신뢰도를 정할 수 없다. 체계적 손상은 고밀도 군집을 만들 수 있고, 모델 불일치의 영향을 받은 정상 측정은 저밀도가 될 수 있다.
- **W2**: 성능 이득이 제한적이다. App. E에서 계수 오차는 세 문제 모두 PINN-EBM이 약간 낮고, 필드 오차 차이도 여러 칸에서 작다.
- **W3**: 대부분의 실험이 같은 다봉 배경 잡음과 큰 양의 이상치를 쓰며, 실제 PIV에 주입한 손상도 같다.
- **Q1**: 상관된 손상에서도 이점이 유지되는가.
- **Q2**: PINN-EBM 대비 실질적으로 의미 있는 복원 개선이 있는가, 그 조건을 명확히 밝힐 수 있는가.
- **Q3**: "Noise-aware Physics-informed Machine Learning for Robust PDE Discovery (2023)"을 논의해 달라. Fourier 기반 denoising PINN과 비교하면 잡음 가정의 차이가 분명해질 것이다.

## 목표

2점에서 3점으로 올린다. Contribution 점수가 2이므로 "이득이 나는 조건"을 명확히 하는 것이 핵심이다. W1은 방법의 실제 한계이므로 반박하지 않는다.

## W1 대응

**입장: 원리적으로 동의한다. 논문이 이를 어디서 인정했고 어디가 부족했는지 밝힌다.**

- 논문은 Broader Impacts에서만 이 한계를 언급한다. Discussion의 한계 문단으로 올리겠다고 약속한다.
- 리뷰어가 든 두 경우를 나눠 답한다.
  - **고밀도 군집을 이루는 체계적 손상**: 손상이 측정의 다수가 되거나 좁은 군집을 이루면 밀도 기준은 이를 정상으로 본다. 이는 방법의 전제(손상은 잔차 분포의 저밀도 영역에 있다)가 깨지는 경우다. Prop. 1(c)의 superlevel-set 해석이 바로 이 전제를 명시한다.
  - **모델 불일치로 저밀도가 된 정상 측정**: 실제 PIV 실험이 이 경우를 포함한다. 명목 2-D Navier–Stokes는 근사인데도 게이트는 손상의 98.99% / 99.23%를 제외하면서 정상 측정은 2.95% / 4.23%만 제외했다(Cylinder 10% / 15%).
- **불리한 사례를 먼저 밝힌다.** FSI에서 naPINN이 rMSE로 OrPINN에 뒤진 것은 이 우려와 부합하는 사례로 제시한다(논문 App. F의 정확한 수치 확인 후 인용).
- E3의 지속 drift 결과가 나오면, 실패 센서 비율이 늘 때 정상 측정 제외율이 어떻게 변하는지 함께 보고한다. 기존 `λ_rej = 0.10` 실행에서는 drift 20% / 30%에서 정상 측정을 8.4% / 32.7% 제외했다. 이 수치는 E3 결과로 대체한다.

## W2, Q2 대응

**입장: 시뮬레이션에서의 우위는 주장하지 않는다. 이득이 나는 조건을 두 가지로 명시한다.**

논문 §5.1도 대부분의 칸이 표준편차 이내라고 이미 쓴다. 답은 다음 구조로 한다.

1. **인정**: 정확한 시뮬레이터에서 두 방법은 비슷하다. 계수 복원은 PINN-EBM이 세 문제 모두에서 약간 낫다(0.72% / 6.46% / 1.02% vs 0.92% / 7.20% / 1.36%).
2. **조건 1, 손상이 심할 때**: λ–ω에서 10% / 15% 손상일 때 naPINN의 rMAE가 19% / 27% 낮다(0.074 vs 0.091, 0.076 vs 0.104). Allen–Cahn에서도 10%, 15%에서 naPINN이 낮다(0.110 vs 0.131, 0.134 vs 0.153). 5%에서는 차이가 없다.
3. **조건 2, PDE가 근사일 때**: 실제 Cylinder PIV에서 rMAE가 31% / 52% 낮다(10%: 0.155 vs 0.224, 15%: 0.160 vs 0.336). PINN-EBM은 `w_PDE`에 민감하고(논문 App. F의 0.424 vs 0.336) seed 간 표준편차가 훨씬 크다. PINN-EBM에는 문제별 `w_PDE` 스윕을 주었고 naPINN은 단일 설정이다.
4. **성능 외의 차이**: naPINN은 측정값별 포함 결정을 내놓으므로 어느 측정이 제외됐는지 확인할 수 있다. PINN-EBM의 likelihood 가중은 이를 주지 않는다.

**주의할 점**

- 작성 서버의 재실행에서는 시뮬레이션 PINN-EBM이 논문보다 훨씬 좋게 나온다(README 3절). 대응문에서는 논문 수치만 쓰고, 시뮬레이션에서 naPINN이 낫다는 새 주장은 하지 않는다.
- "실질적으로 의미 있는가"에 대한 정직한 답은 "정확한 시뮬레이터에서는 아니고, 손상이 심하거나 PDE가 근사일 때는 그렇다"이다. 이 문장을 그대로 쓴다.

## W3, Q1 대응

**입장: 한정적이라는 지적을 인정하고, 실제 PIV에 구조적 손상을 주입한 실험(E3)으로 답한다.**

- 이미 있는 증거: App. G의 Laplace, Gaussian 배경.
- **새 실험 E3**: Cylinder PIV 학습 센서에 일곱 가지 구조적 손상을 주입한다. 시간 상관 AR(1), 공간 burst, 센서 지속 drift(실패 센서 10% / 20% / 30%), 상태 의존 이분산, u–v 성분 간 상관. naPINN은 논문과 같은 `λ_rej = 0.5`로 돌린다.

## Q3 대응

**입장: 논의와 인용을 추가한다. 과제와 잡음 가정이 다르고 서로 보완적이라고 설명한다.**

대상 논문은 Thanasutives, Morita, Numao, Fukui, "Noise-aware physics-informed machine learning for robust PDE discovery", Machine Learning: Science and Technology 4, 015009 (2023), arXiv:2206.12901이다. `AISTATS2027/references.bib`에 아직 없다.

초록 수준에서 확인한 내용은 다음과 같다. **본문을 읽고 확인한 뒤에 대응문을 쓴다.**

| | nPIML (Thanasutives et al.) | naPINN |
|---|---|---|
| 과제 | PDE discovery. 방정식 형태를 모름 | 방정식 형태가 주어진 inverse 문제. 계수와 필드 복원 |
| 구성 | solver와 preselector 네트워크를 함께 학습 → sparse regression과 정보 기준으로 PDE 선택 → denoising PINN으로 계수 미세조정 | 잔차 밀도 추정 → 측정값별 게이트 → 제외 비용 |
| 잡음 처리 | DFT 기반으로 잡음을 줄인 변수에서 학습 | 측정값을 바꾸지 않고 포함 여부를 정함 |
| 잡음 가정 | 주파수 영역에서 신호와 분리되는 잡음(확인 필요) | 잔차 분포의 저밀도 영역에 있는 손상. 분포 형태는 가정하지 않음 |
| 데이터 | 격자 데이터(확인 필요) | 흩어진 희소 센서 |

답의 요점은 세 가지다.

1. 과제가 다르다. nPIML은 방정식을 찾고 naPINN은 주어진 방정식 아래에서 측정을 고른다.
2. 잡음 가정이 다르다. Fourier 기반 denoising은 신호가 저주파에 있고 잡음이 넓은 대역에 퍼져 있다는 가정에 기대며 규칙 격자가 필요하다. 한 측정에 가해진 큰 편차(gross outlier)는 주파수 영역에서 넓게 퍼지므로 필터로 제거되지 않고 주변으로 번진다. naPINN의 설정은 흩어진 센서와 gross outlier다.
3. 두 방법은 보완적이다. 격자 데이터에서는 denoising 단계 뒤에 게이트를 둘 수 있다.

Fourier denoising baseline 실험은 계획하지 않는다. 우리 벤치마크의 측정은 규칙 격자가 아니어서 DFT를 직접 적용할 수 없기 때문이며, 이 점 자체가 답의 일부다. 벤치마크의 센서 배치가 실제로 비격자인지는 대응문 작성 전에 `pinnlab/experiments/`에서 확인한다.
