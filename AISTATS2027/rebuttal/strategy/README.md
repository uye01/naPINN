## 2. 공통 원칙

1. **인정할 것은 먼저 인정한다.** 세 리뷰어의 지적 중 상당수는 논문이 이미 부분적으로 인정한 내용이다(§5.4의 손실 의존성, App. E의 계수 오차, Broader Impacts의 밀도 한계). 방어보다 범위 재설정이 설득력 있다.
2. **주장을 다시 세운다.** "어떤 잡음에도 맞는 방법"이 아니라 "학습된 잔차 밀도를 측정값별 포함 결정에 쓰는 방법이며, 이득은 손상이 심하고 잡음이 비대칭·다봉일 때와 PDE가 근사일 때 난다"로 정리한다.
3. **새 수치는 조건과 함께 낸다.** 유리한 조건만 고르지 않는다. 실험 명세에 조건 목록을 먼저 고정하고, 결과가 불리해도 전부 보고한다.
4. **논문 수치와 다른 계보의 수치를 섞지 않는다.** 아래 3절 참조.
5. **대응문은 영어, 내부 문서는 한국어.**

## 3. 증거 계보 주의사항 (실험 전에 반드시 읽을 것)

논문의 수치는 두 계보에서 나왔다.

- **ten-trial 계보**: 논문 Table 1, Table 2, App. G 잡음 종류 표 등. 원 서버에서 수집.
- **three-seed 계보** (seed 40–42): 논문 Table 3 등. 이 저장소의 `scripts/rebuttal/run_synthetic.py`로 재실행.

이 문서를 작성한 서버에서 `run_synthetic.py`로 재실행한 기록(`outputs/rebuttal/`, git에는 없음)은 아래 네 항목에서 논문과 다르다.

| 항목 | 논문 | 작성 서버 재실행 (seed 40–42) |
|---|---|---|
| PINN-EBM 시뮬레이션, 15%, rMAE (AC / Bu / λω) | 0.153 / 0.077 / 0.104 | 0.103 / 0.047 / 0.040 |
| \|r̃\| 학습 게이트, Table 3, rMAE (AC / Bu / λω) | 0.244 / 0.345 / 0.148 | 0.244 / 0.086 / 0.067 |
| Gaussian 배경 λ–ω 15% rMSE, naPINN vs LAD | 0.126 vs 0.109 | 0.073 vs 0.098 |
| Laplace 배경 λ–ω 15% rMSE, naPINN vs LAD | 0.085 vs 0.085 | 0.075 vs 0.089 |
| 상관 손상 실제 PIV | 원고에서 삭제 | `λ_rej = 0.10` 실행뿐 |

반대로 아래 방법은 작성 서버 재실행과 논문이 일치한다(15%, rMAE, AC / Bu / λω).

| 방법 | 논문 | 작성 서버 재실행 |
|---|---|---|
| naPINN | 0.134 / 0.072 / 0.076 (Table 1, ten-trial), 0.092 / 0.082 / 0.071 (Table 3, three-seed) | 0.092 / 0.082 / 0.071 |
| OrPINN q = 2.9 | 0.269 / 0.175 / 0.150 | 0.268 / 0.191 / 0.153 |
| LAD-PINN | 0.352 / 0.242 / 0.190 | 0.383 / 0.256 / 0.191 |
| PINN (MSE) | 0.823 / 0.568 / 0.437 | 0.855 / 0.586 / 0.422 |

이에 따른 규칙은 다음과 같다.

- 새 실험은 **naPINN, MSE, LAD, OrPINN만 쓰는 비교**를 기본으로 한다. 이 네 방법은 계보 충돌이 없다.
- 실험 서버에서는 본 실험 전에 **앵커 재현(E0)** 을 먼저 돌려 위 표의 값이 재현되는지 확인한다. 재현되지 않으면 본 실험을 시작하지 않고 저자에게 보고한다.
- PINN-EBM과 |r̃| 게이트를 포함하는 새 비교는 저자가 결정하기 전에는 대응문에 쓰지 않는다(5절 D2).
- 대응문에서 기존 주장의 근거는 **논문에 실린 수치**로 댄다.

## 4. 리뷰어 공통 주제와 답의 일관성

세 리뷰가 겹치는 지점이 있어 답이 서로 어긋나지 않게 맞춘다.

| 주제 | 제기한 리뷰어 | 공통 답 |
|---|---|---|
| 잡음·손상 유형이 한 가지 | rchu W2, aQS2 W3 | 인정. Prop. 1(c)의 예측과 묶어 잡음 형태 스윕(E4)과 상관 손상 실험(E3)으로 답함 |
| 이득이 나는 조건 | aQS2 Q2, rchu W1 | 손상이 심할 때, 잡음이 비대칭·다봉일 때, PDE가 근사일 때. 대칭·단봉 잡음에서는 robust loss와 비슷하거나 뒤질 수 있음 |
| 밀도의 역할과 한계 | aQS2 W1, 25xJ | 밀도는 순위로만 쓰이며 추정 품질은 AUROC로 정량화. 밀도만으로 신뢰도를 보장하지 못하는 경우는 한계로 본문에 올림 |
| 과장된 문구 | rchu W1, W3 | 초록의 "no single fixed loss" 문장과 2.0–2.4배 표현을 수정하겠다고 약속 |

## 5. 저자 결정 사항

- **D1. 마감과 형식.** 리버털 마감일(시간대 포함), 글자 수 제한, 수정 PDF 제출 가능 여부가 아직 확인되지 않았다. 실험 범위와 답의 형식("수정본에 반영함" 또는 "최종본에 반영하겠음")이 여기에 달려 있다.
- **D2. |r̃| 게이트와 PINN-EBM을 새 실험에 포함할지.** rchu W2에 가장 직접적인 답은 "모드 간격이 줄어들면 밀도 순서와 크기 순서의 차이가 사라진다"를 보이는 것이고, 이는 naPINN과 |r̃| 게이트의 비교다. 그런데 |r̃| 게이트는 3절의 충돌 항목이다. E0b에서 실험 서버가 어느 값을 재현하는지 먼저 확인한 뒤 결정한다.
- **D3. Gaussian·Laplace 재실행 수치를 쓸지.** 작성 서버의 three-seed 결과는 rchu W1에 유리하지만 App. G와 같은 조건인데 값이 다르다. 권고는 논문 수치만으로 답하는 것이다. 쓴다면 두 세트를 나란히 제시해야 한다.
- **D4. 상관 손상 결과가 혼재일 때의 처리.** E3는 약한 상관 잡음에서 LAD가 앞서고 지속 drift에서 naPINN이 앞설 가능성이 높다. 권고는 일곱 조건을 모두 보고하고 "이득이 유지되는 조건"으로 답하는 것이다.
