# 리뷰어 25xJ 대응 전략

점수 4, 확신 4. Soundness 4, Clarity 4, Contribution 3.

## 리뷰 요지

- **강점으로 인정한 것**: 글과 구성이 좋음, 기법이 흥미롭고 실험에서 유효함, ablation이 구성요소의 가치를 보여줌.
- **약점 1**: 밀도 추정 구성요소의 효과를 평가하지 않았다. 밀도 추정은 예측 모델보다 어렵고, 분포를 잘못 가정하면 영향이 클 수 있다. 추정 품질을 시험할 수 있는가.
- **약점 2**: 구성요소가 어떻게 상호작용하는지 더 깊은 분석이 필요하다. 밀도와 게이트를 모두 켠 경우와 게이트를 고정한 경우의 차이가 매우 크다. rejection cost도 마찬가지다.
- **질문**: rejection cost는 `(1 − g_i)`의 기댓값이고 잔차 `r_i`를 포함하지 않는다. 중간 크기 잔차 여러 개를 버리는 것이 큰 잔차 하나를 버리는 것보다 유리해지는 경우가 있지 않은가. 그렇다면 목표는 전체 raw loss가 아니라 이상치를 뺀 test 예제의 loss여야 하지 않는가.
- **사소한 지적**: 3쪽 하단에서 EBM이 정의 전에 쓰였다. 7쪽 하단의 "we report the widening as an association"이 불명확하다.

## 목표

4점을 유지하고 Contribution을 3에서 올린다. 이 리뷰어의 질문은 대부분 기존 결과와 Prop. 1로 답할 수 있다. 답이 길 필요는 없고 정확해야 한다.

## 약점 1: 밀도 추정 품질

**입장: 정량 지표를 제시하고, 밀도가 순위로만 쓰인다는 설계 논리를 설명한다.**

1. **정량 지표 (E2)**
   - 학습된 밀도 점수만으로 손상 측정을 가려내는 AUROC. 작성 서버의 naPINN three-seed 실행에서는 아홉 조건 모두 0.991–0.997이다. 게이트의 손상 제외율은 98.7–99.4%, 정상 측정 제외율은 0.35–1.1%다. 실험 서버의 앵커 실행(E0)에서 다시 계산해 그 값을 쓴다.
   - 학습된 밀도와 실제 주입한 잡음 밀도 사이의 거리. 시뮬레이션에서는 주입한 잡음을 알고 있으므로 계산할 수 있다. 명세는 `experiment_plan.md` E2.
2. **논문에 이미 있는 증거**
   - Fig. 3 왼쪽: 학습된 밀도와 잔차 히스토그램.
   - 추정기 교체(EBM, GMM, KDE) 결과.
   - 실제 PIV의 손상 제외율 98.99% / 99.23%.
3. **설계 논리**
   - 밀도는 detach된 잔차에 맞추고, 미니배치 안에서 표준화한 log-density의 순위로만 게이트에 들어간다. 따라서 밀도 값의 절대 정확도가 아니라 컷오프 근처의 순서만 맞으면 된다.
   - 분포 형태를 가정하지 않는다. 1차원 EBM은 비모수적이며, 리뷰어가 우려한 "잘못된 분포 가정"은 robust loss(Laplace, q-Gaussian 가정) 쪽에 해당한다.
   - 1차원 밀도 추정은 수만 개의 표본이 있을 때 어려운 문제가 아니다. 리뷰어의 일반론(밀도 추정은 어렵다)은 고차원에서 성립한다.

**주의할 점**

- Student-t 배경에서는 추정기 AUROC가 0.975로 높은데도 게이트가 이상치를 거의 제외하지 않았다(작성 서버 three-seed). 밀도 품질이 좋아도 `λ_rej`와 잡음 스케일이 맞지 않으면 게이트가 작동하지 않는다는 뜻이다. "밀도가 정확하면 충분하다"는 식으로 쓰지 않는다.

## 질문: rejection cost에 잔차가 없다

**입장: 오해를 풀어준다. 잔차는 데이터 항을 통해 들어가며, 리뷰어가 제안한 기준은 Prop. 1(a)가 이미 말하는 것이다.**

1. 측정값 하나의 목적함수 기여는 `g_i r_i² + λ_rej (1 − g_i)`다. `g_i`에 대해 선형이므로 `r_i² > λ_rej`이면 제외하고 그렇지 않으면 포함하는 것이 최적이다. 따라서 제외 여부는 측정값마다 `r_i²`와 `λ_rej`를 비교해 정해지며, 그 결과가 truncated loss `min{r_i², λ_rej}`다(Prop. 1(a)).
2. 리뷰어의 시나리오에 대한 답: `r² < λ_rej`인 측정을 제외하면 그 측정의 기여가 `r²`에서 `λ_rej`로 커진다. 따라서 중간 크기 잔차 여러 개를 버리는 것이 유리해지는 경우는 없다. 반대로 `r² > λ_rej`인 측정을 포함하면 손해다. 목적함수는 가장 큰 잔차부터 제외한다.
3. 실제 게이트는 자유 변수가 아니라 밀도 점수의 sigmoid이므로 위 최적 조건을 평균적으로만 만족한다. Prop. 1(b)가 이를 말한다: 정류점에서 `g(1−g)`로 가중한 평균 제곱 잔차가 `λ_rej`와 같다.
4. 평가 지표에 대한 답: 논문의 rMAE, rMSE는 손상되지 않은 기준 해(시뮬레이션)와 손상되지 않은 held-out 센서(PIV)에서 계산한다. 리뷰어가 제안한 "이상치를 뺀 test loss"와 같은 기준이다. 본문에서 이 점이 분명하지 않았다면 문장을 추가한다.

## 약점 2: 구성요소 상호작용

**입장: Table 3에서 상호작용 크기를 직접 계산해 보이고, rejection cost와 게이트의 관계를 표로 정리한다.**

1. **2×2 상호작용 대비 (Table 3, 15%, rMAE, three seeds)**

   | 순서 기준 | 고정 게이트 | 학습 게이트 | 게이트 학습의 효과 |
   |---|---|---|---|
   | 학습된 밀도 (AC / Bu / λω) | 0.675 / 0.514 / 0.351 | 0.092 / 0.082 / 0.071 | 0.583 / 0.432 / 0.280 |
   | \|r̃\| (AC / Bu / λω) | 0.509 / 0.373 / 0.237 | 0.244 / 0.345 / 0.148 | 0.265 / 0.028 / 0.089 |

   게이트를 학습하는 효과가 밀도 순서일 때 훨씬 크다. 상호작용 대비(두 효과의 차이)는 0.318 / 0.404 / 0.191이다. 리뷰어가 본 "극적인 차이"는 두 요소의 상호작용이다.

2. **메커니즘**: frozen-gate 진단에서 고정 게이트는 손상의 21–28%만 제외하고 학습 게이트는 약 99%를 제외한다. 초기 컷오프(τ̃ = 2)가 손상 비율에 맞지 않기 때문이며, 학습된 컷오프는 손상 5 / 10 / 15%에서 2.8 / 1.8 / 1.3으로 수렴한다(Fig. 6). 밀도 순서가 정확해도 컷오프가 맞지 않으면 쓸 수 없고, 컷오프를 학습해도 순서가 틀리면 잘못된 측정을 제외한다.

3. **rejection cost와 게이트**: `λ_rej`별 손상 제외율을 표로 추가한다. 작성 서버의 Allen–Cahn 15% 스윕은 다음과 같다. 논문 Fig. 5의 값과 같은 계보인지 확인한 뒤 쓴다.

   | `λ_rej` | 0.10 | 0.30 | 0.50 | 0.70 | 1.00 |
   |---|---|---|---|---|---|
   | rMAE | 0.089 | 0.091 | 0.092 | 0.099 | 0.869 |
   | 손상 제외율 | 약 99.3% (0.10–0.70) | | | | 2.1% |

   `λ_rej`가 이상치의 제곱 잔차보다 커지면 게이트가 제외를 멈춘다. Prop. 1(b)의 예측이다.

4. **손실과의 상호작용**: App. G의 naPINN-L1, naPINN-q2.9 결과로 답한다. 게이트는 손실과 결합할 수 있고, 최선의 조합은 inlier 잡음에 달려 있다(rchu W1의 답과 같은 내용).

**주의할 점**

- Table 3의 |r̃| 학습 게이트 행(Bu 0.345, λω 0.148)은 작성 서버 재실행 값(0.086, 0.067)과 다르다(README 3절). 상호작용 대비를 대응문의 중심 근거로 삼기 전에 E0b의 결과를 확인한다. 재실행 값을 넣으면 Burgers와 λ–ω에서는 |r̃| 순서에서도 게이트 학습의 효과가 크게 나와 상호작용 논증이 달라진다.

## 사소한 지적

- **EBM 정의 위치**: 처음 등장하는 곳에서 "energy-based model (EBM)"으로 풀어 쓴다.
- **"we report the widening as an association"**: 의도는 "손상 비율이 높을수록 naPINN과 baseline의 격차가 커지는 것을 관찰했으나, 인과 관계를 검증한 실험은 아니다"이다. 이 뜻이 드러나게 문장을 다시 쓴다. 논문 7쪽의 해당 문장과 앞뒤 맥락을 확인한 뒤 수정안을 만든다.
